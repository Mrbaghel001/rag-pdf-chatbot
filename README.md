# RAG Document Question Answering System

This project implements a Retrieval-Augmented Generation (RAG) pipeline using LangChain, Hugging Face models, and FAISS vector database.

## Features

- PDF document ingestion
- Text chunking
- Embeddings generation
- Semantic search
- LLM-based question answering

## Tech Stack

- Python
- LangChain
- Hugging Face Transformers
- FAISS
